Understanding Foundation Models

You don't need to build a foundation model, but you do need to understand one: how it was trained, how it produces text one token at a time, and which dials change its output. These mental models explain most of the model behavior you'll ever debug.

The sampling dials

Three controls shape how the next token gets picked. They're the first thing to check when output is too random — or too repetitive.

Key takeaways

  • It only predicts the next token All apparent reasoning, knowledge, and style emerge from that one trick applied at scale.
  • Base ≠ assistant Pretraining creates capability; supervised and preference finetuning create the helpful behavior you actually interact with.
  • Outputs are samples The same prompt can produce different answers. Design and evaluate for a distribution, not a single response.
  • Know your dials Temperature and top-p trade consistency for creativity; token limits explain many "truncated" bugs.
