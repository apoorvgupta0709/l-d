Chapter 6

RAG & Agents

Two patterns extend what a model can do: RAG gives it knowledge it doesn't have, and agents give it the ability to act — planning, using tools, and iterating toward a goal.

The RAG pipeline

Retrieval-augmented generation has two halves: an offline indexing job, and an online query path that assembles the best context for each question.

Retrieval strategies

Semantic search isn't the only option — and the best systems combine two.

The agent loop

An agent is a model in a loop: it plans, acts through tools, observes what happened, and repeats until the goal is met.

Key takeaways

  • RAG = search + prompt Its quality ceiling is retrieval quality. Debug the retriever before blaming the model.
  • Hybrid beats either alone Keyword search catches exact terms, embeddings catch meaning — combine and rerank.
  • Agents are models in loops Plan → act → observe → reflect, with tools as their hands. Your executor controls what those hands can touch.
  • Errors compound Multi-step autonomy multiplies per-step failure rates. Reflection, step budgets, and human gates keep agents safe and solvent.
